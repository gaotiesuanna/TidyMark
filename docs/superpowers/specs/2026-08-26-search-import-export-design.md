# 导入导出页搜索设计

## 背景

导入导出页当前展示完整的文件夹树。书签库较大时，用户难以快速定位目标文件夹或书签。搜索输入框放置在“全部展开”和“全部收起”按钮右侧，搜索结果仍使用树形结构展示。

## 已确认需求

- 搜索范围包含文件夹名称、书签标题和 URL。
- 搜索使用不区分大小写的包含匹配，输入后实时更新。
- 搜索结果保留必要的祖先文件夹，维持原目录层级。
- 搜索时自动展开包含命中结果的路径。
- 清空搜索后恢复搜索前用户自己的展开状态。
- 空输入保持当前完整目录树。
- 无结果时显示明确的空结果提示。
- 搜索不修改已勾选项；文件夹勾选继续沿用现有级联逻辑。
- 文件夹可以被勾选；书签只作为结果展示，不参与文件夹范围勾选。

## 方案

在现有 `BookmarkTree` 上增加过滤树能力，而不是维护第二套搜索结果组件。这样可以复用当前的层级缩进、文件夹计数、勾选和展开交互，避免完整树与搜索树的行为分叉。

### 组件职责

- `TransferStep`
  - 持有 `searchQuery`。
  - 渲染搜索输入框。
  - 根据当前查询生成搜索展开状态，并把查询传给 `BookmarkTree`。
  - 记录搜索开始前的展开集合，清空查询后恢复它。
- `BookmarkTree`
  - 递归过滤节点。
  - 保留命中节点及其祖先文件夹。
  - 同时渲染文件夹和书签结果。
  - 继续接收并调用现有勾选、展开回调。

## 过滤算法

递归处理每个 `BookmarkNode`，返回过滤后的节点和是否命中：

1. 使用 `query.trim().toLocaleLowerCase()` 作为匹配文本；空查询直接返回原树。
2. 文件夹节点匹配自身标题；书签节点匹配自身标题或 URL。
3. 递归过滤子节点。
4. 当前节点自身命中，或存在过滤后的子节点时保留当前节点。
5. 对文件夹节点保留过滤后的子节点，保证搜索结果只包含相关分支；祖先文件夹仅因后代命中而保留。
6. 从过滤树收集所有具有结果后代的文件夹 ID，作为搜索期间的自动展开集合。

文件夹节点命中自身时保留该文件夹，但不因为文件夹标题命中而展开并显示其全部无关后代。这样搜索目录名称不会重新产生完整大树，同时仍能让用户定位并勾选目标文件夹。

## 展示与交互

- 搜索框使用原生 `input type="search"`，提供中文 placeholder 和可访问标签。
- 文件夹行保持现有展开按钮、勾选框、名称和书签数量。
- 书签行使用缩进保持层级，展示书签标题和 URL；不渲染文件夹勾选框。
- 搜索期间，展开按钮仍可用，但只影响当前搜索结果；清空查询后恢复搜索前的展开集合。
- 如果当前查询无匹配，树区域显示本地化的“没有找到相关书签”文案。
- 输入框不会改变导入/导出切换状态，也不会触发 store busy 状态。

## 状态边界

- `searchQuery` 和搜索前展开集合是 `TransferStep` 的本地 UI 状态，不写入全局 store。
- 树数据变化时，过滤结果由最新 `tree` 重新计算。
- 清空查询时若记录的展开 ID 已不在最新树中，树组件自然忽略这些 ID。
- `checkedIds` 保持原引用和语义；过滤只影响可见行，不清理隐藏节点的勾选。

## 测试设计

在 `tests/sidepanel/TransferStep.test.tsx` 覆盖：

1. 输入文件夹名称时显示该文件夹及祖先层级。
2. 输入书签标题时显示匹配书签及祖先文件夹。
3. 输入 URL 时显示匹配书签及祖先文件夹。
4. 匹配路径自动展开，多层结果可见。
5. 清空搜索恢复搜索前的展开状态。
6. 无匹配时显示空结果提示。
7. 搜索不影响已有勾选；搜索结果中的文件夹仍可级联勾选其隐藏子目录。
8. 空输入仍保留现有导入/导出切换与格式按钮行为。
